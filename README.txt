Surasaki’s Matcher v2

Состав:
- index.html — офлайн Safari-приложение
- english_10letter_dictionary.txt — 8 816 10-буквенных записей из CMU Pronouncing Dictionary, фильтр a-z

Режимы:
1) Словарь
2) Brute-force 10 x a-z
3) Свой список

Brute-force не создаёт гигантский TXT: кандидаты вычисляются по индексу 0..26^10-1.
Checkpoint сохраняется в localStorage.

ПРИМЕЧАНИЕ:
Словарь в комплекте не является математически «полным английским языком». Полные/крупные
SCOWL/ESDB словари существенно шире и имеют собственные лицензии/варианты. Для текущей
задачи в комплект включён локальный набор 10-буквенных кандидатов без пробелов/цифр/знаков.
