Цель проверки

Кандидаты из словарей / перебора проверяются локально. Для Bitcoin Core wallet.dat требуется корректный mkey (ciphertext, salt, nDeriveIterations, nDerivationMethod). Если данных недостаточно — приложение явно сообщит об этом, а не выдаст ложный результат.

Для legacy Bitcoin Core используется фактический nDerivationMethod=0: EVP_BytesToKey(AES-256-CBC, SHA-512), salt ровно 8 байт и заданное число итераций. PBKDF2 здесь не используется. Для достоверного FOUND нужны также ckey и public key: одна только CMasterKey не содержит MAC.
